## 本地运行

```bash
npm install
npm run dev      # 本地开发
npm run build    # 生产构建（输出 dist/）
```

## 部署

推送到 `main` 分支后，GitHub Actions 自动构建并部署到 GitHub Pages（见 `.github/workflows/deploy.yml`）。
